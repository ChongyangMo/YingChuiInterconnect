# 鹰锤互联

鹰锤互联用于通过局域网或附近设备无线直连，在 iPad 上查看并控制 Mac。当前范围只包含 iPad 与 Mac，Windows 已暂停。

## 当前能力

- Bonjour 自动发现并广播稳定主机 UUID 与协议版本，无需输入 IP；
- TLS 1.3 控制通道、五分钟有效的六位配对码、主机级每分钟最多五次尝试、证书固定与钥匙串可信令牌；
- iPad Retina 虚拟显示器：有物理屏时镜像，无物理屏时创建独立虚拟桌面；ScreenCaptureKit 采集，镜像结束时恢复原显示配置，恢复失败明确提示；
- VideoToolbox H.264 / HEVC 硬件编码，双方支持时优先 HEVC，启动或持续输出失败时回退 H.264；关闭 B 帧，关键帧按恢复需要请求；
- 编码前限制在途任务及网络排队，保留最近真实变化并有界补交，避免先编码加密再因拥塞丢弃；
- 接收端声明视频格式范围，发送端联合校验尺寸、帧率、H.264 宏块吞吐和已声明的解码吞吐；未知吞吐保持未知，不以面板刷新率冒充实测帧率；
- ChaCha20-Poly1305 认证加密 UDP 视频通道，首包认证后绑定来源，拒绝其他来源接管；支持分片、乱序重组、残缺帧淘汰和关键帧恢复；
- 关键帧按发送队列预算双包复制，降低局域网偶发 UDP 丢包造成的恢复等待；
- 根据当前 iPad 原生像素与方向动态请求匹配分辨率，保持 Mac 原始宽高比，不裁切、不拉伸，也不对低像素源画面做无意义放大；
- 流畅、均衡、清晰、原生四档画质；原生档自动匹配 iPad 的 60/90/120 Hz 屏幕，码率随帧率提升至 30/45/60 Mbps，并按输出像素量保留最低清晰码率；
- 画质档位和 Mac 显示器选择自动记忆，播放中可直接切换画质；
- 记住上次成功配对的 Mac，一键连接并在首帧解码成功后进入全屏；
- 全屏软件键盘支持中文、密码和常用特殊键，长文字分段发送并显示执行结果；
- 全屏断线或播放失败显示原因及重试按钮；
- Mac 可信设备列表支持单台撤销，显示当前控制设备，同一时刻只有一个控制会话；
- “更多”集中提供键盘、画质、声音、诊断导出和双向文字剪贴板；
- 主动发送或获取文字剪贴板，限制 64 KiB，通过 TLS 传送，不自动监听剪贴板；
- Mac 系统声音通过独立加密 UDP 传到 iPad，48 kHz 双声道 PCM，可在“更多”开关；声音错误明确停止回传；
- 触摸模式支持单指页面滚动、松手惯性和再次落指制动；鼠标键盘模式保留单指移动指针，支持双指滚动/右键、长按拖拽、文字输入与常用 Command 快捷键；
- 控制指令带执行回执；连接中断时 Mac 自动释放仍按下的远程鼠标键；
- iPad 使用独占全屏并隐藏系统浮层；透明前景保留完整画面，高分辨率已解码帧经边缘延展填满异同比例区域，不显示包数和延迟等诊断信息，也不重复实时解码；
- Wi-Fi 变化、心跳超时、iPad 前后台、Mac 休眠唤醒后自动恢复；持续无帧、UDP 接收、解码或采集器异常时按 1/2/4 秒重建，连续失败后明确停止；仅连续五个统计周期出现真实解码进展才清空重试预算；
- Mac 菜单栏快捷控制与登录时启动；
- iPad 与 Mac 共用鹰翼、锤与连接节点品牌图标；
- RTT、控制执行往返、输入至后续采集帧、采集至接收分位数、接收/解码/丢帧统计和诊断分享；
- 最近诊断事件写入系统日志并包含在诊断分享中；
- 令牌与证书指纹一次保存，旧记录仅完整时迁移；存储失败停止信任建立。Keychain、TLS、编码、加密、UDP 与解码异常明确记录。
- Mac App 专属 TLS 私钥授权失效时会轮换安全身份，并明确提示 iPad 重置信任；测试运行不会访问生产钥匙串或启动局域网服务。
- 双端包含 App Store 隐私清单，声明无跟踪、无开发者数据收集及本地设置/计时用途。

局域网不等于加密网络，因此控制仍使用 TLS 1.3，视频使用低开销逐包认证加密。

## 运行

1. 用 Xcode 打开 `YingchuiInterconnect.xcworkspace`。
2. 先运行 `YingchuiMac`，允许“辅助功能”和“屏幕与系统音频录制”。
3. 在真机 iPad 上运行 `YingchuiPad`；最低支持 iPadOS 17.0。
4. 允许局域网访问，选择 Mac 并输入首次配对码。
5. 选择“原生”并开始回传；网络波动时只自动调整编码码率，不降低所选分辨率。

当前协议版本为 9，最低兼容版本为 9。视频能力和最低协议字段均为可选扩展，旧版协议 9 的客户端继续使用 H.264；新双端协商 HEVC。兼容范围有交集时采用共同版本，未知可选消息可跳过，已知消息字段损坏仍明确断开。原有 TLS、证书固定和可信令牌要求保持强制。有效的 UUID 配对凭据继续使用，Mac 改名不会导致信任失效；证书发生变化时可在 iPad 连接页选择“重置信任”。

再次使用可点“连接上次 Mac”。全屏点右上“更多”调用键盘、剪贴板、画质、声音与诊断导出。剪贴板为空直接提示错误。本轮九项功能的验证结果见 `FEATURE_UPGRADE.md`。

旧版按主机名称保存的完整凭据会保留；TLS 证书匹配、Mac 确认旧令牌有效后，原子迁移到稳定主机 UUID。证书或令牌无法恢复旧授权时进入正常配对流程，输入当前六位码即可。真正损坏或冲突的记录明确报错，不能仅凭旧名称信任新主机。见 `PAIRING_MIGRATION_FIX.md`。

声音发送和播放容量按采样时长限制，修复启动突发被误判“声音队列已满”；首个视频关键帧缺失会明确请求补发。修复与真机验证记录见 `AUDIO_QUEUE_FIX.md`。

回传期间 Mac 阻止自动息屏和空闲休眠，结束后释放保护，不修改系统永久设置。主动锁屏或休眠仍遵循系统行为；见 `DISPLAY_SLEEP_FIX.md`。

## 手势

| 操作 | 触摸模式 | 鼠标键盘模式 |
| --- | --- | --- |
| 单指滑动 | 滚动页面 | 移动 Mac 指针 |
| 单指轻点 | 点击触摸位置 | 点击当前指针位置 |
| 长按约半秒后移动 | 拖拽窗口、文件或选择文字 | 拖拽 |
| 双指轻点 | 右键 | 右键 |
| 全屏双指滑动 | 滚动 | 滚动 |

触摸模式下，快速滑动后松手会逐渐减速，再次落指立即制动；慢速滑动保留细小位移。开启 iPad“减弱动态效果”时不启动松手惯性。预览中的双指手势用于缩放和移动预览，Apple Pencil 保留直接拖动。

硬件键盘支持方向键、Escape、Return、Tab、Delete，以及 Command-A/C/V/W/X/Z 和 Command-Shift-Z。

## 网络建议

- 没有路由器时，两端保持无线局域网开关开启、允许本地网络访问，在 iPad 中选择附近的 Mac 配对；不需要加入同一网络或开启热点。关闭无线局域网开关后无法无线直连。
- 无路由器模式使用苹果点对点无线链路，发现和建连可能需要约 30 秒；距离、干扰和系统调度会影响延迟与流畅度，不能保证与路由器连接相同的性能。
- 配对、画面、声音和控制均走本地连接，无需互联网；邮箱登录、账户同步和下载更新仍需要互联网。
- iPad 使用 5 GHz/6 GHz Wi-Fi，并关闭低数据模式；
- Mac mini 优先通过网线连接同一路由器；
- 避免访客网络、AP 隔离、拥挤信道与远距离弱信号。

## 自动验证

2026-09-08 修复了码率函数编译错误，并完成安全、视频解码、故障恢复与模块拆分。详细执行结果见 `REPAIR_VALIDATION.md`。

随后补齐连接生命周期：旧配置与旧端口回调不能重新激活已停止的视频；单台主机身份失败不会封锁其他主机；扫描错误直接显示；视频失败统一清理资源。显式地址连接、身份确认、配对响应分别限制为 10、5、10 秒，超时明确断开并提示重新选择主机。附近服务连接允许 30 秒发现并在连接超时后重新解析服务；身份与配对验证超时仍终止。

本地可复现验证：

```sh
python3 Tools/validate.py
```

验证任务和目标模拟器写在 `validation.json`，不使用环境变量。任何任务失败即停止并输出错误和日志路径。

“解码帧”现在来自 VideoToolbox 成功输出的像素缓冲区，不再用提交次数冒充；显示层使用同一份已解码图像，不重复解码。该指标仍不代表屏幕扫描已完成。
“输入至后续帧”止于新采集帧抵达 iPad，不包含最终屏幕扫描时间。

## 虚拟显示器与分发

当前产品使用 Mac 站外分发路线。连接会让所选物理屏镜像 iPad Retina 虚拟屏；启动前将显示模式、位置和镜像关系原子写入恢复文件，正常停止并成功恢复后删除文件。异常退出后下次启动显示“恢复显示器”；必须匹配原显示器和模式，无法匹配直接报错并保留记录。暂时断流会短时间保留虚拟屏以避免反复闪屏。

没有物理显示器时，Mac 端根据 iPad 的真实视口尺寸创建独立虚拟桌面，不要求镜像对象，也不生成物理显示器恢复记录。仍有显示器但所选编号无效时明确报错；遗留配置在原屏在线时自动恢复，拔线时保留记录并允许独立桌面使用，重插后再恢复。镜像过程中拔线会保留虚拟桌面，系统终止采集时可在保留控制连接的情况下重建一次采集。无屏模式需在已登录 macOS、Mac 端已运行并完成授权的会话内使用，详见 `HEADLESS_DISPLAY.md`。

`CGVirtualDisplay*` 属于系统内部接口，已增加运行时方法检查和 Objective-C 异常转换，系统不支持时明确停止。此实现不适用于 Mac App Store 提交；系统升级、复杂多屏拓扑和进程被强制终止后的桌面状态仍需单独验收。正式站外分发需要分发签名、公证和装订。

最终触控手感、真实 Wi-Fi 端到端延迟和长时间温度表现仍需在实机使用中验收。

## 性能目标

- 局域网 RTT P95 ≤ 15 ms；
- 控制指令生效 P95 ≤ 30 ms；
- 操作到画面反馈 P50 ≤ 50 ms；
- 连续运行 30 分钟，无崩溃、持续花屏或不可恢复断流。
